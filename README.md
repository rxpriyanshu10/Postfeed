# Postfeed

Postfeed is a lightweight social posting application for sharing image-based updates. Users can create a post by selecting an image and adding a caption, while the feed presents published posts in a simple, focused stream. The backend accepts multipart uploads, stores images through ImageKit, and persists post metadata in MongoDB. The React frontend provides the create-post form and feed view, with the API connecting both experiences. Postfeed is designed as a small, practical foundation for experimenting with media uploads, content feeds, and full-stack JavaScript development.
